01 / APPLIED AIPERSONAL PROJECT

MedQuery AI

A research assistant grounded in PubMed.

Connects medical research questions to relevant abstracts with semantic retrieval and language model responses. Research mode requests citations back to the retrieved papers.

  • Python
  • ChromaDB
  • Sentence Transformers
  • Mistral
  • Streamlit
View source ↗Setup guide ↗
Explore the implementation +
THE CHALLENGE

Make a collection of research abstracts searchable by meaning, while keeping source information connected to each answer.

HOW IT WORKS

PubMed ingestion → MiniLM embeddings → persistent ChromaDB cosine search → a Mistral prompt built from retrieved abstracts. PMID-based IDs avoid duplicate indexing.

ENGINEERING CHOICE

CPU-based embeddings make local experimentation accessible. Paper titles, years, PMIDs, and URLs travel with each retrieval result.

PROJECT SCOPE

A research prototype with source code and local setup instructions. Retrieval quality and generated citations still need systematic evaluation.

02 / DATA SYSTEMSTEAM COURSE PROJECT

TutorHub

Better scheduling starts with better data.

A campus tutoring platform with a normalized MySQL schema, transactional booking, audit trails, and SQL-powered analytics for students, tutors, and administrators.

  • MySQL 8
  • Python
  • Streamlit
  • Plotly
View source ↗Full ER diagram ↗
Explore the implementation +
THE CHALLENGE

Keep tutoring availability and bookings consistent while giving administrators useful views of demand and utilization.

DATA INTEGRITY

Foreign keys and CHECK constraints define valid records. The booking stored procedure uses SELECT … FOR UPDATE to protect the slot during a transaction.

ANALYTICS

Window functions, recursive CTEs, and moving averages support rankings, demand analysis, and reporting. Update triggers retain a booking and slot audit trail.

CONTEXT

Team 11 · EDS 6343, Database Management Tools for Engineers · University of Houston · Spring 2026. The repository includes SQL scripts and a Streamlit interface.
