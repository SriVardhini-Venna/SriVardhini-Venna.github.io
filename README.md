# Sri Vardhini Venna — Portfolio

A black-and-white portfolio focused on Data, AI, and ML, built with HTML, CSS, and JavaScript.

## Contents

- `index.html` — portfolio content, projects, experience, skills, and IEEE publication
- `styles.css` — responsive layout, monochrome styling, reduced-motion and print rules
- `app.js` — mobile navigation, project filters, architecture explorer, and clipboard actions
- `assets/favicon.svg` — vector favicon
- `.nojekyll` — serve the static files directly on GitHub Pages

## Editing and preview

Edit the files in the repository root. No build or dependency installation is required.

For a local preview:

```bash
python -m http.server 8000
```

Open http://localhost:8000.

## GitHub Pages

This repository's existing Pages deployment publishes from `main`. See the **Actions** tab for build and deployment status after each update.

Search indexing is currently disabled through the robots meta tag and `robots.txt`. These directives do not make a GitHub Pages site private.
